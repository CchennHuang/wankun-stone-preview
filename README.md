# WANKUN STONE — Website review

Static website review for the factory. This is not the production enquiry service. No enquiry or file-upload backend is included.

- Default: English
- Chinese: /zh/
- Only public sales contact: Alice Huang
- No PPT source files, private drawings, runtime databases, credentials or other contact details are included.

## Publish

Use a public repository named **wankun-stone-preview**. Upload the contents of this folder to the root of the main branch. In Settings → Pages, select Deploy from a branch, main, /(root), then Save.

Use GitHub's returned published URL after the Pages build succeeds. This package is configured for the /wankun-stone-preview/ project path.
